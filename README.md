# PhET Simulations (`@webwriter/phet-simulation@2.0.0`)
[License: MIT AND GPL-3.0-only AND CC-BY-NC-4.0](LICENSE) | Version: 2.0.0

Explore physics, chemistry, mathematics, and biology with interactive PhET simulations.

The original simulations are by PhET Interactive Simulations at the University of Colorado Boulder. Frederic Salmen adapted them for WebWriter. [PhET Interactive Simulations](https://phet.colorado.edu/)

## Languages

The WebWriter controls and snippet titles are available in Cantonese (Simplified and Traditional), Kurmanji (Latin and Arabic scripts), Sorani Kurdish, and Afrikaans (South Africa and Namibia). The embedded simulation uses the translations included in that PhET simulation. Among the 125 bundled simulations, 121 include Latin-script Kurmanji and 47 include Afrikaans. Cantonese, Arabic-script Kurmanji, and Sorani are available in the WebWriter controls and titles; the embedded simulations use their existing fallback languages.

## `WebWriterPhetSimulation` (`<webwriter-phet-simulation>`)
Embed an interactive PhET simulation and save experiment checkpoints in the document.
See the [usage guide](USAGE.md) for authoring, preferences, and checkpoints.

### Usage

Use with a CDN (e.g. [jsdelivr](https://jsdelivr.com)):
```html
<script type="module" src="https://cdn.jsdelivr.net/npm/@webwriter/phet-simulation@2.0.0/widgets/webwriter-phet-simulation.js"></script>
<webwriter-phet-simulation></webwriter-phet-simulation>
```

Or use with a bundler (e.g. [Vite](https://vite.dev)):

```
npm install @webwriter/phet-simulation
```

```html
<script type="module">
  import "@webwriter/phet-simulation/widgets/webwriter-phet-simulation.js"
</script>
<webwriter-phet-simulation></webwriter-phet-simulation>
```
